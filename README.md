# Otterz plugins for Claude

The Claude plugin marketplace for [Otterz](https://otterz.co).

```
/plugin marketplace add OtterzInc/nyra-claude-plugin
/plugin install nyra@otterz
```

## Plugins

| Plugin | Description |
|---|---|
| [`nyra`](plugins/nyra) | Connect Claude to your live books — P&L, balance sheet, cash position, transactions — and send documents in for processing. |

This repository contains only plugin manifests and documentation. The Nyra MCP server
is hosted at `https://mcp.otterz.co/mcp` and authenticates with OAuth 2.1; its source
is proprietary.
